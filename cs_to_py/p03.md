# Граница

Класс ReportWriter отвечает за запись строк в файл.
В C# для управления ресурсами используется интерфейс IDisposable и его метод Dispose().

В Python ресурсы управляются автоматически с помощью протокола контекстного менеджера:
Открытие файла происходит при входе в блок with через __enter__(),
закрытие — при выходе через __exit__().

# Контракт

__enter__() открывает файл и возвращает текущий объект (self), предоставляя доступ к его методам внутри блока.
__exit__() закрывает файл при любом способе выхода из блока.
__exit__() возвращает False, чтобы исключения не проглатывались.

# Ошибка

Ошибкой считается попытка использовать объект без необходимых методов протокола контекстного менеджера,
а также ошибки, возникающие при работе с файлом, например при его открытии или записи.

Если необходимые методы отсутствуют, ошибка обнаруживается во время выполнения при попытке использовать объект в with.
Исключения внутри блока не подавляются и продолжают распространяться.

# Инвариант

Файл должен оставаться открытым только на время работы внутри контекстного блока.
После выхода из with файл обязательно закрывается независимо от того, завершился блок штатно или из-за исключения.
Исключения, возникшие внутри блока, не подавляются и продолжают распространяться.
